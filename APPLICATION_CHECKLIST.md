# Application Checklist

## Before applying

- [ ] Confirm the exact problem you want to solve
- [ ] Choose a buildathon track
- [ ] Define the target user/customer
- [ ] Write a one-sentence value proposition
- [ ] Describe why agentic AI is required
- [ ] Explain the Caribbean relevance or market opportunity

## Team package

- [ ] Team name
- [ ] Founder / builder bios
- [ ] Roles and responsibilities
- [ ] GitHub repo ready
- [ ] Contact info

## Product package

- [ ] Project name
- [ ] 1-paragraph overview
- [ ] Problem statement
- [ ] Proposed solution
- [ ] Core workflow / agent loop
- [ ] MVP scope for 21 days
- [ ] Demo concept
- [ ] Why now / why this team

## Technical package

- [ ] Chosen stack
- [ ] Model/provider plan
- [ ] Data sources
- [ ] APIs and tools
- [ ] Deployment target
- [ ] Security/privacy notes

## Submission assets

- [ ] README with clear project summary
- [ ] Pitch deck outline
- [ ] Architecture notes
- [ ] Roadmap for the sprint
- [ ] Demo script
- [ ] Investor-facing impact statement

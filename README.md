# FutureCaribbean1

Starter workspace for the Future Caribbean Agentic AI Buildathon.

## Buildathon snapshot

- Organizer: Future Caribbean
- Format: 21-day buildathon sprint
- Applications close: July 3, 2026
- Sprint window: July 17, 2026 to August 7, 2026
- Winners announced: September 1, 2026
- Teams selected: 40
- Prize pool: US$70,000 total
- IP: teams retain ownership

## Current repo purpose

This repository is set up to help turn an idea into a submission-ready project with:

- challenge framing
- track selection
- product definition
- technical architecture
- MVP planning
- demo prep
- application materials

## Repo structure

- `BUILDATHON_NOTES.md` - summarized event notes and assumptions
- `APPLICATION_CHECKLIST.md` - what to prepare for applying and submitting
- `IDEA_CANVAS.md` - define the actual project idea
- `DATA_SOURCES.md` - recommended data stack and source strategy
- `PITCH_PARAGRAPH.md` - buildathon-ready pitch paragraph
- `docs/MVP_ARCHITECTURE.md` - agentic climate-risk MVP architecture
- `docs/COPERNICUS_INGESTION_PLAN.md` - focused plan for Copernicus Marine MVP ingestion
- `docs/AMOC_ATLAS_REFERENCE.md` - reference note for AMOC Atlas and its role in the project
- `docs/SENSOR_GRID_REVIEW.md` - review of a possible future sensor compression concept
- `docs/` - place for architecture, pitch, and research notes
